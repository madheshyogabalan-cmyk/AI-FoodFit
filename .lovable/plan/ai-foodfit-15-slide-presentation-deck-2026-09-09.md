# AI FoodFit — 15-Slide Presentation Deck

A downloadable PowerPoint file (.pptx) covering the whole project, ready to present in class or a review.

## Look and feel

- Dark charcoal title and closing slides, light slides in between (sandwich structure)
- Forest green as the dominant colour, lime as the sharp accent, cream/off-white for light slides
- Header font Georgia, body Calibri; big titles, readable 20-24pt body text
- One visual on every slide: stat callouts, icon rows, comparison columns, timeline, or a generated food/app illustration
- Repeated motif: lime circle icon badges next to section headers

## Slide list

1. Title — AI FoodFit, tagline, presenter block: **Y. Madhesh, AIML B, RTC**, hero visual of healthy Indian food
2. Problem — no calorie/macro awareness for everyday Indian food, generic diet advice, budget ignored
3. Solution overview — one app: analyse, score, swap, plan, track, ask
4. How it works — 4-step flow: set profile → log food → get score and swaps → track progress
5. Onboarding and personal targets — profile inputs and how daily calorie/macro/water targets are derived
6. Home dashboard — calories/protein rings, carbs/fat/fibre/water bars, streaks
7. Food analyzer — natural-language search ("2 idli"), photo recognition, quick-add Indian foods
8. Nutrition result card — health score 0-100, macros and micros, pros and cons
9. Evaluation system — Better Choice / Moderate / Limit Frequency instead of good vs bad
10. Healthier and cheaper swaps — before/after comparison columns
11. Meal planner and budget mode — breakfast, lunch, snack, dinner with cost estimate; plan for a set daily budget
12. Progress tracking and reports — timeline, editable history, weekly charts, downloadable weekly report
13. FoodFit AI assistant — bilingual English and Tamil/Tanglish nutrition chat
14. Technology, security and privacy — React + TypeScript app, cloud accounts with email/Google sign-in, each person sees only their own data, wellness-estimate disclaimer
15. Future scope and thank you — barcode scanning, wearables, more languages, dietitian connect, live app link

## Content rules

Every number, feature and screen description comes from the app as built. No invented users, funding, revenue or accuracy metrics. Slide 1 shows Y. Madhesh, AIML B, RTC; no presentation date unless you give me one.

## Technical notes

- Generated with pptxgenjs in a Node script, 16:9 slides
- Illustrations generated as images and embedded as base64 so the file is self-contained
- Validated with the pptx schema validator, then rendered to images and visually reviewed slide by slide, fixing overflow/overlap before delivery
- Delivered as an attachment in chat; the app itself is not modified
